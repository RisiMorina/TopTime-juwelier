# Top Time, juwelier in Deventer

Website voor Top Time, juwelier en horlogemaker aan de Spijkerboorsteeg in Deventer. Live op [toptimejuwelier.nl](https://toptimejuwelier.nl).

Ontworpen en gebouwd door Eris (2026). Getoond met toestemming van de eigenaar.

## Wat het is
- Statische one-pager in plain HTML, CSS en JavaScript, zonder build of framework.
- GSAP en ScrollTrigger lokaal in `js/vendor/` voor rustige scroll-animatie; de site werkt ook zonder JavaScript.
- Lettertypen zelf gehost, Google Maps pas na een klik, geen tracking.
- Respecteert `prefers-reduced-motion`.

Lokaal bekijken: open `index.html` in de browser.

## Rechten
De code is alleen ter inzage als portfoliowerk; er is geen open-source licentie. Foto's, teksten en reviews zijn van Top Time. De merklogo's zijn van de merken zelf (bron per logo in `assets/images/merken/LEESMIJ.txt`). Hergebruik niet zonder toestemming.
